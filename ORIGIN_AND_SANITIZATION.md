# Origin and Sanitization Notes

This public v0.1 was reconstructed from a previously tested Spec-Driven workflow and sanitized for public use.

## Preserved ideas

- Product / Engineering authority separation;
- Product Grill;
- small stakeholder decision sets;
- delta re-grill;
- explicit readiness states;
- Engineering Grill against the real repository;
- question classification;
- implementation spec per scoped story;
- small task decomposition;
- independent verification.

## Removed from the public version

- employer-specific context;
- stakeholder names;
- financial institution rules;
- project-specific statuses and examples;
- internal timings, operational windows and file layouts;
- vendor-specific or organization-specific implementation details;
- source-project-specific product decisions.

## Note

The public repository should remain domain-agnostic. Examples should use synthetic or public-domain scenarios only.
